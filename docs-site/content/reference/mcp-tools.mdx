The tools an AI agent can call once you turn on **Let agents use Lilo** in Settings > Agents. Each one has a short summary and the parameters an MCP client sends, with their types, allowed values and whether they are required. To connect an agent, see [AI agents](/guides/ai-agents).

What holds for every tool:

- The tools Claude in Chrome has keep its names and shapes, so an agent written for it needs nothing new. Lilo adds more, such as the Web Inspector, network and profile tools.
- An agent works in its own folder, which the tool descriptions call its tab group. `tabId` is the number `tabs_context_mcp` and `tabs_create_mcp` give for a tab of that folder, and an agent reaches only the tabs of its folders. An agent connected from another app works in an Agents Space, in the Agents profile until you allow one of yours; an agent in a Lilo conversation works in the conversation's folder of your own Space, with that Space's profile and your sign-ins. No agent reaches one of your Private Spaces. These tools are all Lilo gives an agent: a conversation agent's own file and command tools are the agent's, not Lilo's, and none of what follows applies to them.
- Some actions wait for your approval, unless you turn off **Ask before sending, paying, deleting or publishing**: a click or Enter on a button, link or form whose label or form address contains one of a fixed list of words such as "send", "pay", "delete" or "publish", and a request other than GET or HEAD with the cookies of one of your profiles. The word check is best effort: clicks on other kinds of element, other labels, other languages, icons and Enter in a message box pass without a question. Whatever that setting, Lilo asks before an agent hands a page one of your files. Opening a local file with `navigate` and reading it asks nothing. [Agent safety](/about/agent-safety) explains what the approvals cover and what they do not.
- A parameter description below is the text the agent itself reads.
