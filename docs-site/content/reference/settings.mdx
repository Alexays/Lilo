Every row of Settings, in the order Settings shows them, with the text the row itself shows. Open Settings with **Lilo > Settings…** (<kbd>⌘,</kbd>), or type in **Search settings** to find a row by name.

How to read the tables:

- Sections and groups follow the Settings sidebar and the headings inside each section.
- **Default** is the position of an on/off switch on a new installation. Rows that open a list, a menu or a page leave it empty: what they start with depends on your Mac or is shown in the row.
- Some rows appear only while the switch above them is on: the rows after **Block ads and trackers** need it on, for example, and so do the rows after **Let agents use Lilo**.
- The **Terminal** section is described in [Terminal](/guides/terminal).
