Every action you can give keys to, grouped by the menu it sits in, with its default shortcut. An action marked "—" has no default: you can give it one. A few keys are fixed and not listed here: keys that act only where you are, such as <kbd>Esc</kbd> or the arrows in a list, and **Edit > Spelling and Grammar > Show Spelling and Grammar**, which keeps macOS's standard Command-colon.

## Change a shortcut

1. Choose **Help > Keyboard Shortcuts** (<kbd>⌘/</kbd>). Settings opens on **Keyboard shortcuts**, in the **General** section.
2. Click a shortcut, then press the new keys. <kbd>Esc</kbd> cancels, <kbd>Delete</kbd> leaves the action without a shortcut.
3. If another action already uses those keys, Lilo names it: choose **Replace** to move the keys, or **Cancel**.

**Reset** restores one action's default, and **Reset All** every one. Next to **Preset**, the **Lilo** and **Arc** buttons start from Lilo's defaults or from Arc's; clicking one replaces every shortcut you changed. **Control-Tab switches tabs in** chooses between **Recent Order**, which shows your last tabs from every Space until you release Control, and **Sidebar Order**.

A shortcut you set for Lilo in macOS System Settings, under **Keyboard > Keyboard Shortcuts > App Shortcuts**, takes precedence over Lilo's own. Lilo reads those at launch, so quit and reopen it after changing one.

For more on presets and the other ways to adapt Lilo, see [Customize Lilo](/guides/customize).
