Lilo runs Chrome extensions on WebKit and fills in many of the Chrome APIs WebKit lacks. This page lists only what is missing or differs from Chrome, and the store extensions that were tested: an API not listed here behaves as in Chrome. To install and manage extensions, see [Extensions](/guides/extensions).

The text below comes from the project's compatibility tracker, [COMPATIBILITY.md](https://github.com/Alexays/Lilo/blob/main/COMPATIBILITY.md), and is written for extension developers as much as for people using Lilo. To see whether an extension you use works, go to [Tested store extensions](#tested-store-extensions): its table gives each extension's status. The paragraphs above that table describe how the project tests extensions: names such as `make ext-smoke`, `top-extensions.json` or `RealExtensionSmokeTests` are the project's own test commands and files, which you do not need to use Lilo. If an extension you rely on misbehaves and its problem is not here, [report it](https://github.com/Alexays/Lilo/issues).
