Lilo renders every page with WebKit, the engine of Safari. This page lists the web features where Lilo differs, how Lilo handles each, and the limitations of WebKit and macOS that Lilo cannot work around. When a site misbehaves, check here first, then see [Troubleshooting](/guides/troubleshooting).

The text below comes from the project's compatibility tracker, [COMPATIBILITY.md](https://github.com/Alexays/Lilo/blob/main/COMPATIBILITY.md). Extension APIs are covered in [Extension compatibility](/reference/extension-compatibility).
