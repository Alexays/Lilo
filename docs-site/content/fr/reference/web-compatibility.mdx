Lilo affiche chaque page avec WebKit, le moteur de Safari. Cette page répertorie les fonctions web pour lesquelles Lilo diffère, la manière dont Lilo gère chacune d'elles, et les limites de WebKit et de macOS que Lilo ne peut pas contourner. Quand un site se comporte mal, consultez d'abord cette page, puis reportez-vous à [Dépannage](/guides/troubleshooting).

Le texte ci-dessous provient de l'outil de suivi de compatibilité du projet, [COMPATIBILITY.md](https://github.com/Alexays/Lilo/blob/main/COMPATIBILITY.md). Les API d'extension sont traitées dans [Compatibilité des extensions](/reference/extension-compatibility).
