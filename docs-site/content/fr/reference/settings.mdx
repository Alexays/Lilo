Les lignes des Réglages, dans l'ordre où les Réglages les affichent, avec le texte que la ligne elle-même affiche. Les listes et les cartes que les Réglages affichent entre les lignes, comme vos espaces et vos profils, vos extensions installées ou les tuiles d'apps sous **Apps qui peuvent utiliser Lilo**, ne sont pas reprises ici. Ouvrez les Réglages avec **Lilo > Réglages…** (<kbd>⌘,</kbd>), ou saisissez du texte dans **Rechercher un réglage** pour trouver une ligne par son nom.

Comment lire les tableaux :

- Les sections et les groupes suivent la barre latérale des Réglages et les titres à l'intérieur de chaque section.
- **Par défaut** est la position d'un interrupteur sur une nouvelle installation. Les lignes qui ouvrent une liste, un menu ou une page laissent cette colonne vide : leur état de départ dépend de votre Mac ou est affiché dans la ligne. **Installer les mises à jour automatiquement** n'affiche pas non plus de valeur par défaut : ce réglage est activé dans une version que vous installez, et une version compilée depuis les sources ne se met pas à jour elle-même.
- Votre réponse à la question **Comment allez-vous utiliser Lilo ?** de la configuration change deux valeurs par défaut : **Avec mes agents** et **Pour développer** activent **Laisser les agents utiliser Lilo**, et seul **Pour développer** laisse **Onglets terminal** activé.
- Certaines lignes n'apparaissent que lorsque l'interrupteur situé au-dessus d'elles est activé : les lignes qui suivent **Bloquer pubs et traqueurs** nécessitent qu'il soit activé, par exemple, tout comme les lignes qui suivent **Laisser les agents utiliser Lilo**.
- La section **Terminal** est décrite dans [Terminal](/guides/terminal).
