# Getting help

Lilo is maintained by volunteers in their spare time. These are the fastest ways to get an answer.

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/Alexays/Lilo/discussions): how to do something,
whether a feature fits, help building from source. Search first, someone may have asked already.

## Bugs

Open an [issue](https://github.com/Alexays/Lilo/issues/new/choose) with the bug report template.
It asks for your Lilo and macOS versions and the steps to reproduce. **Help > Diagnostics** has
**Copy report** and **Copy extension logs** buttons whose output helps a lot;
[docs/DEBUGGING.md](docs/DEBUGGING.md#6-logs) shows how to collect logs.

## An extension that does not work

Check [COMPATIBILITY.md](COMPATIBILITY.md) first: it lists what still differs from Chrome. If your
extension is not covered, open an issue with the extension compatibility template.

## Security vulnerabilities

Never in public. Follow [SECURITY.md](SECURITY.md) to report one privately.
