Lilo — браузер для Mac для тих, хто звик працювати з бічною панеллю. Це не черговий форк Chromium.
Його написано на Swift і AppKit, а рушій — уже наявний у macOS WebKit. Водночас він запускає
розширення Chrome, якими ви користуєтеся. Вкладки термінала розміщуються поруч зі сторінками,
а ваші звичні агенти ШІ можуть керувати браузером через вбудований сервер MCP у власному просторі.
Безкоштовно, за ліцензією MIT, без облікового запису. Якщо ви переходите з Arc, простори,
закріплені вкладки й папки імпортуються за кілька клацань.

> **Стан: публічна бета-версія.** Lilo можна користуватися щодня, але це ще бета-версія: можливі
> недоліки та зміни інтерфейсу. [Повідомляйте про те, що не працює](https://github.com/Alexays/Lilo/issues).
> [ROADMAP.md](../../ROADMAP.md) містить пріоритети та те, що не входить у плани.

Приєднуйтеся до [спільноти в Discord](https://discord.gg/NyJRAapk76), щоб поділитися відгуком або отримати допомогу з Lilo.

## Чому Lilo

Більшість альтернатив Arc — це Chromium із новою бічною панеллю. Lilo зберігає бічну панель і змінює решту.

- **Без Chromium.** Без окремо вбудованого рушія браузера й без Electron: Swift, AppKit і системний WebKit,
  а бічна панель і параметри — на Svelte. Менше використання пам’яті, батарея на весь день
  та оновлення безпеки Apple з кожним випуском macOS.
- **Приватність від початку.** Без облікового запису, телеметрії, аналітики й сервера: жодні ваші дії
  не надсилаються проєкту. Реклама й трекери блокуються відразу, міжсайтове відстеження блокується,
  як у Safari, а Global Privacy Control увімкнено (macOS 27). Кожен самостійний запит Lilo
  [описано разом зі способом вимкнення](../../PRIVACY.md#requests-lilo-makes-on-its-own).
- **І розширення Chrome теж.** Вихід із Chromium зазвичай означає відмову від його розширень.
  У Lilo розширення з Chrome Web Store інсталюються одним клацанням «Додати до Lilo»
  на нативному середовищі WebKit ([COMPATIBILITY.md](../../COMPATIBILITY.md)).
- **Ваші агенти керують ним; власного ШІ немає.** Без доданого чатбота: агенти, якими ви вже
  користуєтеся (Claude Code, Codex, Cursor або будь-який клієнт MCP), працюють зі справжнім браузером
  через вбудований сервер MCP. Вони мають власний простір і тимчасовий профіль та питають вас
  перед надсиланням, оплатою або видаленням.
- **Термінал поруч зі сторінками.** Вкладки термінала на основі Ghostty розміщуються на бічній панелі
  разом із сайтами та показують гілку й незафіксовані зміни репозиторію.
- **Ваш.** Ліцензія MIT. Увесь інтерфейс — це шар Svelte над WebKit, який можна змінити
  та перебудувати за лічені секунди.

## Можливості

**Перегляд**

- **Простори й профілі**: простори з емодзі та кольором, кожен зі своїми сеансами входу в окремому
  профілі. Перемикайте їх проведенням. У приватних просторах після закриття нічого не залишається.
- **Бічна панель**: закріплені вкладки, улюблене, папки до п’яти рівнів вкладеності (можна блокувати),
  впорядкування перетягуванням, керування аудіо й поточним відтворенням.
- **Панель команд** (`Cmd+T`): вкладки, історія, закладки, простори й усі дії в одному полі,
  упорядковані відповідно до використання.
- **Недавні вкладки** (`Ctrl+Tab`): переходьте між останніми вкладками з усіх просторів у порядку
  їх використання.
- **Попередній перегляд**: посилання із закріпленої вкладки на інший сайт або будь-яке посилання,
  клацнуте з `Shift`, відкривається над сторінкою.
- **Мале вікно** (`Cmd+Option+N`, з будь-якої програми): невелике вікно для одного посилання або пошуку,
  яке можна перенести до простору, коли воно знадобиться надовше.
- **Автоматичний порядок у вкладках**: незакріплені вкладки архівуються після часу бездіяльності,
  вибраного для кожного простору. `Cmd+Shift+K` очищає їх, а архів доступний одним скороченням.
- **Правила посилань**: посилання з інших програм спрямовуються в простір або мале вікно, вибране правилом.
- **Розділений перегляд**: до чотирьох вкладок поруч, із відновленням після перезапуску.
- **Клавіатурні скорочення**: кожне можна змінити, почавши з набору Lilo або Arc.
- **Імпорт**: закладки, відкриті вкладки й простори, історія, файли cookie та розширення із Safari,
  Firefox, Zen і браузерів Chromium (Chrome, Arc, Brave, Edge, Vivaldi, Opera, Dia, Comet,
  Chromium) читаються безпосередньо з вашого Mac.

**Розширення й веб**

- **Розширення Chrome**: Manifest V3 через нативне середовище розширень WebKit, а також невеликі
  обробники Swift для API, яких бракує у WebKit ([COMPATIBILITY.md](../../COMPATIBILITY.md)).
- **Менеджери паролів**: початкове налаштування пропонує той, яким ви користуєтеся (1Password,
  Bitwarden, Dashlane, KeePassXC, NordPass, Proton Pass).
- **Потокове відтворення**: захищені відео й музика через FairPlay; YouTube у 4K HDR.
- **Блокування вмісту**: постійно оновлювані списки EasyList, EasyPrivacy та uBlock Origin,
  із приховуванням елементів і скриптлетами.
- **Знімки екрана**: знімок з’являється як картка над сторінкою, готова до редагування з розміткою,
  збереження або закриття.
- **І ще більше**: режим читання, «Кадр у кадрі» (виклики на панелі поверх інших вікон), переклад
  сторінок, Web Serial, AppleScript, дії Швидких команд і фільтр зосередження.

**Для розробників**

- **Вкладки термінала**: термінали libghostty-vt з рендерингом Metal поруч зі сторінками
  (`Cmd+D` — поруч, `Cmd+Shift+D` — знизу), з гілкою та незафіксованими змінами на бічній панелі.
- **Перегляд змін**: усі відмінності репозиторію, включно із зображеннями.
- **Не засинає під час роботи**: довга команда не дає Mac заснути навіть із закритою кришкою,
  а після завершення знову дозволяє сон.
- **Агенти через MCP**: вбудований сервер MCP, див. [Для агентів ШІ](#для-агентів-ші).

## Для агентів ШІ

Lilo має вбудований сервер MCP. Увімкніть його, і ваші звичні агенти (Claude Code, Claude Desktop,
Codex, Cursor або будь-який клієнт MCP) керуватимуть справжнім браузером WebKit поруч із вами.
У Lilo немає власного ШІ.

- **Власний простір.** Агенти відкривають вкладки в папці простору «Агенти» у тимчасовому профілі,
  що очищається після кожного сеансу. Вони не займають клавіатуру, мишу чи ваші вкладки та не бачать
  приватних просторів. З вашого дозволу агент може скористатися одним із ваших профілів.
- **Спершу — ваша згода.** Lilo запитує дозвіл перед надсиланням, оплатою, видаленням або публікацією
  (Дозволити раз, Завжди дозволяти на цьому сайті або Відхилити), а також перед передаванням
  сторінці одного з ваших файлів. Кожен клієнт потребує одноразового схвалення та прив’язується
  до справжньої програми, а не до назви, яку вона повідомляє.
- **Одне клацання для підключення.** У Параметри > Агенти ШІ ввімкніть «Дозволити агентам ШІ використовувати Lilo»,
  а потім натисніть «Під’єднати» поруч із Claude Code, Claude Desktop, Codex або Cursor. Lilo додасть
  себе до серверів MCP цього клієнта. Для іншого клієнта скопіюйте конфігурацію з розділу «Інші агенти».

Потім попросіть агента, наприклад:

```text
Відкрий localhost:3000/checkout у Lilo, оплати тестовою карткою та з’ясуй, чому замовлення не вдається.
Перевір консоль і мережу.
```

Інструменти охоплюють:

- **Вкладки й навігацію** в папці агента та ізольовані вкладки без спільних файлів cookie чи сеансів входу.
- **Введення**: клацання, текст, клавіші, прокручування, перетягування, заповнення форм, передавання
  файлів і зображень.
- **Читання сторінок**: дерево доступності з посиланнями на елементи, пошук тексту, текст сторінки.
- **Знімки екрана** всієї сторінки або одного елемента та записи GIF.
- **Консоль і мережу**: повідомлення, запити з повними відповідями, експорт HAR, файли cookie.
- **Імітацію мережі й емуляцію**: імітовані, невдалі чи затримані запити; ідентифікатор браузера,
  колірну схему, зменшення руху, режим друку, додаткові заголовки, початкові скрипти, розмір області перегляду.
- **Продуктивність**: показники завантаження й відображення, пам’ять і профілі часової шкали.
- **Вебінспектор**: власний протокол інспектора WebKit, команди й події.
- **Скрипти**: JavaScript на сторінці, `fetch` із вкладки з її файлами cookie та `run` або
  `browser_batch` для об’єднання багатьох викликів в один обмін.
- **Профілі**: перегляд списку, використання профілю з вашого дозволу або скидання тимчасового профілю.

Докладно в [docs/AI-AGENTS.md](../../docs/AI-AGENTS.md): що запитується, що ні та які помилки
потребують вашої участі.

## Інсталяція

Виберіть один зі способів:

- завантажте DMG з [випусків](https://github.com/Alexays/Lilo/releases/latest) або
- інсталюйте через Homebrew:

  ```bash
  brew install --cask alexays/tap/lilo
  ```

Lilo оновлюється через підписані оновлення Sparkle.

### Вимоги

- macOS 26 або новіша. Для Global Privacy Control потрібна macOS 27.

## Збирання з вихідного коду

З інстальованими Xcode 27 та Node.js 22.6+ ([повні вимоги](../../CONTRIBUTING.md#requirements)):

```bash
git clone https://github.com/Alexays/Lilo.git && cd Lilo
make bootstrap                  # checks the prerequisites and fetches or builds what the app needs
make install                    # Release build into /Applications, replacing an installed copy
open /Applications/Lilo.app
```

`make bootstrap` повідомляє, чого бракує та як це інсталювати. Команда перевіряє вимоги й отримує або
збирає потрібні компоненти. `make install` створює збірку Release у `/Applications`, замінюючи
інстальовану копію. Для роботи лише над інтерфейсом достатньо Node.js: `make ui-preview` відкриває
його в браузері з миттєвим оновленням ([CONTRIBUTING.md](../../CONTRIBUTING.md#interface-only)).

Обліковий запис Apple Developer не потрібен. Збірки з вихідного коду типово підписуються ad hoc.
[CONTRIBUTING.md](../../CONTRIBUTING.md#signing) пояснює обмеження та підписування за допомогою
безкоштовного Apple ID.
