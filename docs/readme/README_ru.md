Lilo — браузер для Mac для тех, кто привык к боковой панели, а не очередной форк Chromium.
Он написан на нативных Swift и AppKit и использует движок WebKit, уже встроенный в macOS,
при этом поддерживая нужные вам расширения Chrome. Вкладки терминала находятся рядом со
страницами, а привычные вам ИИ-агенты могут управлять браузером через встроенный MCP-сервер,
каждый в своём пространстве. Бесплатно, под лицензией MIT, без учётной записи. Если вы уходите
с Arc, Lilo импортирует пространства, закреплённые вкладки и папки за несколько нажатий.

> **Статус: публичная бета.** Lilo подходит для повседневного использования, но всё ещё находится
> в бете: возможны недоработки, а интерфейс продолжает меняться. Пожалуйста,
> [сообщайте о проблемах](https://github.com/Alexays/Lilo/issues).
> В [ROADMAP.md](../../ROADMAP.md) перечислены приоритеты и то, что не входит в планы проекта.

Присоединяйтесь к [сообществу в Discord](https://discord.gg/NyJRAapk76), чтобы делиться отзывами и получать помощь с Lilo.

## Почему Lilo

Большинство альтернатив Arc — это Chromium с новой боковой панелью. Lilo сохраняет боковую
панель и меняет всё остальное.

- **Без Chromium.** Без собственного браузерного движка в комплекте и без Electron: Swift,
  AppKit и системный WebKit, с боковой панелью и настройками на Svelte. Меньше расход памяти,
  батарея на весь день и обновления безопасности Apple с каждой версией macOS.
- **Приватность по умолчанию.** Без учётной записи, телеметрии, аналитики и сервера: никакие ваши
  действия не отправляются проекту. Реклама и трекеры блокируются сразу, межсайтовое отслеживание
  заблокировано как в Safari, а Global Privacy Control включён (macOS 27). Каждый запрос,
  который Lilo отправляет самостоятельно,
  [перечислен вместе со способом его отключения](../../PRIVACY.md#requests-lilo-makes-on-its-own).
- **Расширения Chrome остаются.** Уход с Chromium обычно означает отказ от его расширений.
  В Lilo расширения из Chrome Web Store устанавливаются одним нажатием «Добавить в Lilo»
  через нативную среду выполнения WebKit ([COMPATIBILITY.md](../../COMPATIBILITY.md)).
- **Ваши агенты управляют браузером, собственного ИИ в нём нет.** Никакого добавленного чат-бота:
  агенты, которыми вы уже пользуетесь (Claude Code, Codex, Cursor или любой MCP-клиент), работают
  с настоящим браузером через встроенный MCP-сервер, в своём пространстве и временном профиле.
  Перед отправкой, оплатой или удалением они спрашивают вашего разрешения.
- **Терминал рядом со страницами.** Вкладки терминала на основе Ghostty находятся в боковой
  панели вместе с сайтами и показывают ветку и ожидающие изменения своего репозитория.
- **Ваш браузер.** Лицензия MIT. Весь интерфейс — слой Svelte поверх WebKit, который можно
  изменить и пересобрать за секунды.

## Возможности

**Работа в браузере**

- **Пространства и профили**: пространства с эмодзи и цветом, каждое с авторизацией своего
  профиля; переключайтесь между ними смахиванием. Приватные пространства забывают всё при закрытии.
- **Боковая панель**: закреплённые вкладки, избранное, папки с вложенностью до пяти уровней
  и возможностью блокировки, сортировка перетаскиванием, управление звуком и текущим воспроизведением.
- **Панель команд** (`Cmd+T`): вкладки, история, закладки, пространства и все действия в одном
  поле, отсортированные по частоте использования.
- **Недавние вкладки** (`Ctrl+Tab`): переключение между последними вкладками из всех пространств
  в порядке их использования.
- **Peek**: ссылка с закреплённой вкладки на другой сайт или любая ссылка, открытая с зажатой
  клавишей `Shift`, открывается поверх страницы.
- **Мини-окно** (`Cmd+Option+N`, из любого приложения): небольшое окно для ссылки или
  поиска, которое можно отправить в пространство, когда понадобится продолжить работу.
- **Вкладки, которые убирают за собой**: незакреплённые вкладки, которыми вы перестали пользоваться,
  архивируются через выбранное для пространства время; `Cmd+Shift+K` очищает их, а архив доступен
  по одному сочетанию клавиш.
- **Правила для ссылок**: ссылки из других приложений открываются в пространстве или мини-окне,
  указанном правилом.
- **Разделённый вид**: до четырёх вкладок рядом, с восстановлением после перезапуска.
- **Сочетания клавиш**: любое сочетание можно переназначить, взяв за основу набор Lilo или Arc.
- **Импорт**: закладки, открытые вкладки и пространства, история, cookie и расширения из Safari,
  Firefox, Zen и браузеров на Chromium (Chrome, Arc, Brave, Edge, Vivaldi, Opera, Dia, Comet,
  Chromium), считанные прямо с вашего Mac.

**Расширения и веб**

- **Расширения Chrome**: Manifest V3 через нативную среду расширений WebKit и небольшие
  обработчики на Swift для недостающих API ([COMPATIBILITY.md](../../COMPATIBILITY.md)).
- **Менеджеры паролей**: при настройке предлагается тот, которым вы пользуетесь (1Password,
  Bitwarden, Dashlane, KeePassXC, NordPass, Proton Pass).
- **Стриминг**: защищённые видео и музыка через FairPlay; YouTube в 4K HDR.
- **Блокировка контента**: обновляемые списки EasyList, EasyPrivacy и uBlock Origin,
  с косметической фильтрацией и скриптлетами.
- **Снимки экрана**: снимок появляется карточкой поверх страницы; его можно разметить,
  сохранить или закрыть.
- **И многое другое**: режим чтения, «Картинка в картинке» (звонки в панели поверх всех окон),
  перевод страниц, Web Serial, AppleScript, действия «Команд» и фильтр фокусирования.

**Для разработчиков**

- **Вкладки терминала**: терминалы libghostty-vt с отрисовкой через Metal рядом со страницами
  (`Cmd+D` — рядом, `Cmd+Shift+D` — снизу), с веткой и ожидающими изменениями в боковой панели.
- **Просмотр изменений**: все различия в репозитории, включая изображения.
- **Не засыпает во время работы**: долгая команда не даёт Mac уснуть, даже с закрытой крышкой,
  а после завершения снова позволяет перейти в режим сна.
- **Агенты через MCP**: встроенный MCP-сервер, см. [Для ИИ-агентов](#для-ии-агентов).

## Для ИИ-агентов

В Lilo есть встроенный MCP-сервер. Включите его, и ваши привычные агенты (Claude Code, Claude
Desktop, Codex, Cursor или любой MCP-клиент) смогут управлять настоящим браузером WebKit рядом
с вами. Lilo не поставляется с собственным ИИ.

- **Своё пространство.** Агенты открывают вкладки в папке пространства «Агенты», во временном
  профиле, который удаляется после каждого сеанса. Они не забирают вашу клавиатуру, мышь или
  вкладки и никогда не видят приватные пространства. Агент может воспользоваться одним из
  ваших профилей с вашего разрешения.
- **Сначала ваше согласие.** Lilo спрашивает разрешение перед отправкой, оплатой, удалением
  или публикацией (разрешить один раз, всегда разрешать на сайте или запретить), а также перед
  передачей странице одного из ваших файлов. Каждый клиент одобряется один раз, с привязкой
  к запустившей его программе, а не к имени, которым он представился.
- **Подключение в один клик.** В разделе «Настройки > ИИ-агенты» включите «Разрешить ИИ-агентам
  доступ к Lilo», затем нажмите «Подключить» рядом с Claude Code, Claude Desktop, Codex или
  Cursor: Lilo добавится в список MCP-серверов клиента. Для других клиентов скопируйте
  конфигурацию из раздела «Другие агенты».

Затем попросите агента, например:

```text
Открой localhost:3000/checkout в Lilo, оплати тестовой картой и выясни, почему заказ не проходит.
Проверь консоль и сеть.
```

Инструменты охватывают:

- **Вкладки и навигацию** в папке агента, а также изолированные вкладки без общих cookie и авторизации.
- **Ввод**: нажатия, текст, клавиши, прокрутку, перетаскивание, заполнение форм, загрузку файлов
  и изображений.
- **Чтение страниц**: дерево доступности со ссылками на элементы, поиск текста и текст страницы.
- **Снимки экрана** всей страницы или отдельного элемента и запись GIF.
- **Консоль и сеть**: сообщения, запросы с полными ответами, экспорт HAR, cookie.
- **Моделирование сети и эмуляцию**: подменённые, неудачные или задержанные запросы; user agent,
  цветовую схему, уменьшение движения, режим печати, дополнительные заголовки, скрипты
  инициализации и размер области просмотра.
- **Производительность**: метрики загрузки и отрисовки, память и профили временной шкалы.
- **Веб-инспектор**: собственный протокол инспектора WebKit, команды и события.
- **Скрипты**: JavaScript на странице, `fetch` из вкладки с её cookie и `run` или `browser_batch`
  для последовательности вызовов за один обмен с сервером.
- **Профили**: список профилей, использование одного с вашего разрешения или сброс временного.

В [docs/AI-AGENTS.md](../AI-AGENTS.md) описано, какие разрешения запрашиваются, какие не нужны
и какие ошибки требуют вашего участия.

## Установка

На выбор:

- скачайте DMG со страницы [релизов](https://github.com/Alexays/Lilo/releases/latest) или
- установите через Homebrew:

  ```bash
  brew install --cask alexays/tap/lilo
  ```

Lilo обновляется автоматически через подписанные обновления Sparkle.

### Требования

- macOS 26 или новее. Для Global Privacy Control нужна macOS 27.

## Сборка из исходного кода

С установленными Xcode 27 и Node.js 22.6+ ([все требования](../../CONTRIBUTING.md#requirements)):

```bash
git clone https://github.com/Alexays/Lilo.git && cd Lilo
make bootstrap                  # checks the prerequisites and fetches or builds what the app needs
make install                    # Release build into /Applications, replacing an installed copy
open /Applications/Lilo.app
```

`make bootstrap` укажет, чего не хватает и как это установить. Для работы только с интерфейсом
достаточно Node.js: `make ui-preview` откроет его в браузере с горячей перезагрузкой
([CONTRIBUTING.md](../../CONTRIBUTING.md#interface-only)).

Учётная запись Apple Developer не нужна. Сборки из исходного кода по умолчанию подписываются
ad hoc; [CONTRIBUTING.md](../../CONTRIBUTING.md#signing) объясняет ограничения и способ подписи
с бесплатным Apple ID.
