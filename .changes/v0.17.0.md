## [0.17.0] - 2026-11-07

### Added

- Group by Project in the tab list's Sort and Group menu gathers the terminals and conversations of one repository in a tray, a worktree's with its main checkout
- A conversation folds each sub-agent into one row under the call that started it, with its latest step, its report and its own tool calls, and several permission requests can wait at once
- The changelog and What's New can show a film, a loop or an image for each highlight, starting with the tab sharing film
- Every release has its own page on getlilo.app, and the changelog has an RSS feed in English and French
- A pop-up window Lilo blocks, one a page opens without a click, shows in the address bar, where its site can be allowed to open pop-ups; the page then opens it on its next try. Site controls list pop-ups too
- Hide Element in the View menu and the page's context menu hides the element you click on that site from then on; the Site drawer and Settings > Sites list what you hid and show it again

### Changed

- Lilo uses less CPU and energy while agents stream their replies, switches spaces faster and loads pages with less work
- Background tabs use less CPU: a tab whose typed text was sent or cleared can be put to sleep again, and muted or runaway off-screen tabs are paused
- Tabs opened in Low Power Mode or under thermal pressure render pages at about 60 fps, whatever the full refresh rate setting, saving battery
- Pages use less CPU and memory: tabs loading out of sight render at full width when shown, ad blocking does less work on large pages and in hidden ones, secure sites connect without waiting on the app, and idle agent tabs, dismissed notifications and translated pages hold less
- The first Space, the default profile, new folders and the Private and Agents Spaces get names in Lilo's language, camera and microphone prompts offer Don't Allow, and Spanish, Portuguese, Russian and Simplified Chinese translate the prompt to share the Mac's sound
- Agent conversations pick up faster after an idle agent restarts, as agents that can resume a session no longer resend its whole history
- Ad-blocking extensions such as AdBlock no longer recompile their rules at every launch
- Conversations start npm agents faster: each version of an agent is installed once and then starts directly, without asking the npm registry or loading your project's files on every start.
- Buttons, menus and segmented controls share one size and corner across Settings and drawers, shortcuts show as the same keycaps everywhere, and a button no longer widens while it works.
- Screenshot confirmations and notices now appear as the same toast as a closed tab, and the screenshot panel uses the standard buttons, Save menu and section headers.
- Popovers share one shape and animation, opening on a spring and fading out when they close, and toolbar icons no longer move on hover
- Close, chevron and plus icons share one drawing with the same line weight across panels, banners, the find bar, the tab strip and the screenshot editor.
- Automatic updates download only what changed since your version instead of the full app
- An open site stack takes the same color as its tabs' glow and shows it as soon as it opens, and a site with a black and white icon stays neutral
- Searching the History page shows results much faster on a large history, and keeping history within its size limit no longer delays address bar suggestions
- Importing from Firefox keeps pinned tabs pinned, and importing from Zen brings each workspace in as a Lilo Space with its pinned and open tabs, and Zen essentials as bookmarked tabs
- What's New opens on a larger headline with the release's first highlight across the sheet, the others side by side below, and every change in grouped lists; films play from a single button instead of the video controls
- The content blocker never accepts cookie consent for you: filter-list rules that would click an accept button or store an accepted answer are dropped, and on sites using Didomi, OneTrust, Cookiebot or Usercentrics, consent is refused through the platform itself while cookie notices are hidden
- An agent that signs in through a terminal now asks for its sign-in in the conversation, without opening a terminal tab
- The address bar of an agent conversation names its project instead of a folder path, or says it has none
- Space and folder colors are picked with a hue and an intensity slider, or taken from anywhere on screen with an eyedropper; the time of day option now shows what it does

### Fixed

- Choosing where the tabs go during onboarding no longer flashes the tab bar over the screen
- The sidebar's resize edge no longer shows through a site's permission prompt or the address details
- A call no longer leaves for picture in picture when you focus an app on another screen or beside the window, which keeps it in view
- An agent that stops on its own always shows the last thing it reported, which says why it stopped
- Unlocking Bitwarden's vault no longer spins forever, as extensions built for Chrome's Symbol.dispose now find it
- A background tab stopped for hanging no longer shows a running hang counter in the sidebar
- A terminal command that keeps printing, like top or tail -f, no longer keeps the Mac awake past the Stop after duration, now set for both keep-awake modes.
- Recently closed terminals are no longer forgotten when Lilo quits unexpectedly
- Extensions can create their offscreen document again after it closes itself, its timers run at full speed, and with the clipboard read permission it can paste as in Chrome
- An extension whose manifest keeps it out of incognito no longer offers to run in private spaces
- Extensions see the title and closing time of recently closed tabs, no longer find notifications blocked before macOS has asked to allow them, and get the download, tab group and history fields Chrome always provides
- Extension updates that only add permissions Chrome grants without a warning, or ones already granted, no longer disable the extension; an update that needs new permissions is listed for review instead of interrupting with a dialog, and background update downloads respect Low Data Mode.
- With the Grain material, the page no longer jumps when its color changes while the sidebar slides
- The picture-in-picture window snaps to its corner without sliding when Reduce motion is on
- Typing in the Settings search stays smooth on a profile with many sites, and the matching sites show the first 100 with a count of the rest
- Extensions no longer see the address or title of tabs in a locked folder.
- The Settings search marks matches in accented and Turkish titles, such as "ecran" in "Écran partagé"
- Extensions that drive a tab through chrome.debugger now deliver keyboard shortcuts and Tab presses to the page.
- The History page no longer reshuffles its list on the first keystroke of a search, and stays responsive while you type or browse with it open
- A tab an extension is debugging with chrome.debugger is no longer frozen or unloaded in the background, which stopped the page and ended the session
- An extension's side panel no longer shows in a private space unless the extension is allowed there, and comes back when you return to a regular space.
- The Extensions menu in the menu bar shows each extension's action as set for the current tab and greys out a disabled action, and clicking a disabled extension icon opens its menu.
- Right-clicking a link, image or selection shows every extension's menu items for it again, with the right link, image or selected text, and a private tab no longer shows items of extensions not allowed in private spaces
- Control-Tab no longer shows the title, address or icon of tabs inside a locked folder.
- Extensions that drive a tab with Puppeteer through chrome.debugger no longer fail at startup, and wait for pages to load as in Chrome
- Unpacked extensions pick up their edited files without restarting Lilo: a new Reload button in Settings > Extensions, `chrome.runtime.reload()` and loading the same folder again all read the folder again. Once the developer tools are unlocked, a release build makes unpacked extensions inspectable at once. Loading a folder whose manifest key matches an installed extension now says so instead of doing nothing.
- An extension's toolbar shortcut opens its side panel as a click on its button does, pressing it or clicking the button again closes its popup, and an extension page asking for the popup no longer runs the button's click action instead
- The keyboard focus ring stands out on the sidebar, toolbars and floating panels, and buttons show when they are pressed.
- Extension pages, such as a new tab override or an options page, no longer open in a private space, and an extension opening a tab no longer takes you out of a private space or switches spaces for a background tab; an options page already open in another space is shown instead of opened again
- An agent conversation closed while its agent starts no longer leaves the agent running, an agent started to replay a reopened conversation or to sign in stops once idle, a crashed agent or a sign-in terminal that cannot open shows an error instead of a stuck sign-in, and picking a mode or model after the agent stopped applies it or says why it could not
- With Reduce motion on, showing or hiding the sidebar or toolbar no longer slides the page, and modals, drawers, toasts, notices, the command bar, the find bar, the tab switcher and the page load line fade in instead of popping up; onboarding also turns opaque with Reduce transparency
- Lilo no longer quits on a filter list regex with an out-of-range repeat count, on an extension's out-of-range scroll delta, scale factor or bookmark index, on a page opening a serial port at a negative baud rate, or on a diff of several gigabytes, which the Changes view now reports as too large to show
- The address bar keeps a long site name's registrable domain in view, marks pages that are not secure before their host, and the Little window shows the site's host in full without any credentials before it
- A site asking for a password over plain HTTP now warns that it will be sent unencrypted and no longer offers to remember it
- Downloads: a canceled or failed download shows its reason in your language, a page-generated file that cannot be saved now appears in the list as failed, and Save Page As marks the saved file as downloaded from the web
- Extension blocking rules apply more like in Chrome, so content blockers such as uBlock Origin Lite no longer block scripts on every site from rules meant for some tabs or responses, no longer match longer host names than the ones listed, and redirect to the full address
- A damaged database no longer stops Lilo from launching: Lilo moves the unreadable file aside, starts with a new, empty database and shows where the damaged file is kept.
- A page's popup window follows the page when it resizes or moves itself, kept on screen
- What's New now opens after a patch update, with that update's notes.
- Choosing the interface language no longer changes the language sites see: they get your system languages, as in Safari
- Help > Report an Issue fills in the Lilo and macOS versions, and the report offered for a frozen page names only its site, not its full address
- After closing a window, an agent conversation it was showing notifies again when its turn ends or it asks for permission
- Keyboard and VoiceOver: the arrow keys walk the Space, folder, archived tabs, profile and screenshot menus, the history list is a single Tab stop walked with the arrow keys, and the shortcut editor names each shortcut and keeps focus through a conflict.
- A conversation whose agent failed shows its red badge in the top tab strip, as it does in the sidebar.
- Opening another app from a page, such as Mail, Zoom or Teams, closes the blank tab or window the page opened for it, opens Mail at once from a clicked email link, and no longer lets a page stack one prompt after another
- Maps and delivery tracking keep following your position after a brief Wi-Fi or GPS drop, and a site's location timeout and cached-position age are honored
- Typing a version number such as v1.2 in a Little window's address field searches the web instead of opening it as a site, and a search engine removed from the list falls back to the first one everywhere.
- Extension managers now see the extensions you install, update, turn on or off and remove from the extensions panel or the Chrome Web Store, instead of keeping a stale list
- Extensions whose manifest.json or translations contain comments install, update and load, as they do in Chrome
- Extension popups, side panels and pages can read your location and show notifications, without asking when the extension declares those permissions
- Extension links to Chrome's extensions or shortcuts page open Lilo's extension settings on that extension, instead of an empty tab asking to open another app
- Password managers linked to their desktop app stay connected, and extensions whose background work outlasts 30 seconds keep running, as in Chrome
- With several windows open, extensions keep seeing the window you are working in as the current one when a space changes in another window.
- Extensions now see each tab's favicon address, and hear through tabs.onUpdated when a tab changes group, is discarded or reloaded, freezes or resumes, or gets a new favicon
- Printing a restored tab that never loaded no longer crashes Lilo.
- Tab extensions can discard tabs of any window, get tab group events for private windows they are allowed in, and can no longer undo another profile's split views
- The first agent of a launch no longer deletes folders you made or locked in the Agents space, only the task folders agents created there
- Removing the last site from an extension's site access no longer gives it back every site: pick All sites or Selected sites, and Selected sites can stay empty.
- Extension shortcuts no longer take keys a Lilo shortcut or another extension already uses, and the extension page names what holds the keys you type
- A conversation closed by mistake comes back with Reopen Closed Tab with its whole thread, its restore points and the pages it had open, and a crash mid-turn no longer loses the prompt that was running
- An extension debugging a tab with chrome.debugger keeps its user agent, emulation and page scripts, and keeps receiving events, when the tab's Web Inspector closes, and one that detaches no longer leaves its overrides on a tab another extension still debugs
- Downloads from a private space no longer appear in other spaces or in notifications, and their list is kept in memory only and cleared when the space closes
- The interface now follows your region for dates and times (for example 24-hour times with English in the UK), uses the right plural forms for counts, joins lists the way your language does, and declares its language to VoiceOver.
- A browser import that fails now says why when it can tell: Keychain access denied, a file in use, or Full Disk Access missing
- A terminal tab whose login shell no longer exists shows the error and opens zsh instead of closing at once
- A screen or window share that macOS fails to start now tells the site the capture could not start instead of saying you refused it
- When a window's interface recovers from a crash, site permission prompts still waiting for an answer show again, a pending share picker closes so the site can ask again, and the command bar and History keep their site icons
- Installing an extension from the address bar or onboarding now reports its real outcome: no false failure while the permissions dialog is open, nothing shown when you cancel, and a translated message when it fails. Extension errors in Settings and in install dialogs are translated and no longer show technical details.
- Native dialogs and notifications use the right plural form in every language, for example "Close 1 terminal?", and the folder deletion prompt reads correctly in Russian, Ukrainian and Polish.
- The drop to pin and drop to bookmark hints stay centered and readable in every language, error messages meet AA contrast, and secondary sidebar text follows Increase contrast
- Every sidebar action works from the keyboard and VoiceOver: a pinned tab goes back to its home page from its context menu, favorite tiles and Space icons open their menu with Shift-F10 and move with Option-arrows, moves and Space switches are announced, and the sidebar width handle resizes with the arrow keys
- Lilo tells you when it cannot save your tabs, settings or a conversation, sets aside an unreadable list of archived tabs or closed terminals instead of overwriting it, and never replaces an agent configuration it cannot read
- Profiles and private spaces keep their own favicons: a site can no longer link them by the icon requests one of them skips
- A tab no longer shows the favicon of the site it just left when that icon was slow to load
- The History page no longer leaves some sites without their favicon while you type or filter
- Sites you allowed to send notifications can now show them from their service workers too
- Closing the password panel of a locked folder now animates like opening it
- A message sent while a conversation waits for a terminal sign-in now runs instead of leaving the conversation busy for good
- Turning a content blocker list on or off while the lists refresh now applies right after that refresh, not at the next one hours later
- Clear Browsing Data closes once the clear is done, never earlier, and no longer stays busy when the clear fails
- Pressing Escape while resizing a screenshot crop no longer leaves the next crop drag resizing instead of drawing
- Pinning a closed bookmark keeps it in the sidebar as a pinned tab
- An extension stopping speech another extension paused no longer leaves text-to-speech paused for good
- An extension's background worker that starts loading while Lilo checks on it is no longer restarted mid-load
- An agent conversation no longer keeps showing the sign-in status under the agent's work once you are signed in
- Tables in an agent's replies now show as tables instead of raw text
- Pages an agent opens now show under its conversation, which unfolds for the first one and keeps following the conversation to another Space or folder
- A message typed in an agent conversation and not sent is kept when you switch tabs
- A message sent to interrupt an agent is no longer lost when the agent ends the stopped turn with an error
- Escape and Command-Return now stop an agent that is using Lilo's browser tools, instead of waiting for the tool to finish
- Typing / in a new agent conversation now lists the agent's commands, without sending a message first
